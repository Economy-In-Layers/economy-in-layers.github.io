EIL Mission Control — Privacy Policy

Last updated: November 9, 2026

EIL Mission Control is a private dashboard used only by the owner of the YouTube channel “The Economy in Layers” to view that channel's own statistics. It is not offered to the public.

What it accesses

  • Read-only access to the owner's own YouTube channel data through the YouTube Data API and the YouTube Analytics API (for example: subscribers, views, watch time, audience retention, traffic sources, estimated revenue).
  • It cannot upload, edit or delete videos, comments or any other content.

Where the data stays

  • The authorization and the data are stored only on the owner's personal computer, encrypted by the operating system.
  • No data is sold, shared with third parties, used for advertising, or transferred to anyone else.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

How to revoke access

At any time at myaccount.google.com/permissions, or by using “Disconnect” in the dashboard.
